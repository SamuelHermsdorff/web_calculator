Sobre o Projeto

Uma Calculadora Desenvolvida com Tecnologias Web Modernas

A Calculadora Premium foi desenvolvida para demonstrar conhecimentos em desenvolvimento Front-end utilizando apenas tecnologias nativas da Web.

O projeto foi construído utilizando HTML5, CSS3 e JavaScript puro, aplicando conceitos como manipulação do DOM, eventos de teclado, responsividade, animações, transições, Grid Layout, Flexbox e efeitos modernos utilizando Glassmorphism.

Além da interface moderna, a aplicação possui suporte ao teclado, cálculos em tempo real e organização completa entre HTML, CSS e JavaScript, seguindo boas práticas de desenvolvimento.
